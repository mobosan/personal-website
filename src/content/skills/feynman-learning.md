## 适合什么场景

想系统学习一个领域、检查是否真正理解某个概念，或根据已有学习记录继续练习。目标、基础和可用时间决定计划；普通事实查询不会自动展开长期陪练。

## 学习循环

**先解释 → 追问与找缺口 → 必要的补充讲解 → 无提示变式 → 延迟验证 → 更新计划。**

它把掌握情况拆成当前层级、证据强度和复习状态。一次答对不等于稳定掌握，历史成绩也不自动代表当前能力；用户只想先听讲解时，仍会尊重该选择。

## 使用示例

安装并确认助手已识别该 Skill 后，可以这样开始：

```text
用 $feynman-learning 帮我学线性代数。
我会高中数学，每周能投入 3 小时，目标是理解机器学习中的矩阵运算。
请先诊断基础，再制定可调整的计划，一次问一个主要问题。
```

也可以说：“这是我对梯度下降的解释，请找出我还没理解的地方。”

## 档案与配套工具

需要保存时，在获准写入的学习工作区维护 `learning/<项目名>/state.json`，记录目标、证据、错误和复习日期；不把个人学习记录写进 Skill 安装目录。没有文件权限时可使用会话内记录及导出的 JSON 快照。

包内的 `scripts/check_state.py` 是可选、只读的结构检查工具。它检查文件格式和引用，不能判断答案是否正确或证明学习效果。示例档案 `assets/example-state.json` 是虚构教学示例。

## 下载包包含

- `SKILL.md` 与 `README.md`：主要工作流、安装与使用说明。
- `references/`：计划、评估、档案约定及跨领域示例。
- `assets/`：空白模板、知识节点模板与虚构示例档案。
- `scripts/`：可选的 Python 档案检查工具。
- `agents/openai.yaml` 与 `VALIDATION.md`：界面信息和历史验证记录。

请解压并保留整个 `feynman-learning/` 文件夹，按所用工具支持的方式安装；包内 README 提供更详细的说明。

## 验证与限制

本次分享包保留原 Skill 的 1.0.0 版本。包内 `VALIDATION.md` 记录的是 2026-09-24 的历史检查，不是本次网站接入的新测试结果。网站接入仅验证页面与下载交付。

核心学习流程不依赖 Python 或联网。自动提醒需要宿主支持调度且由使用者明确要求；Skill 本身不会在后台持续运行。掌握层级和复习间隔属于教学约定，不是经过标定的测量量表。
